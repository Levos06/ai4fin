# Финансовый AI-агент

Агент на базе LLM с тремя инструментами:
1. **Запрос котировок акций** (yfinance) - получение текущих и исторических цен акций
2. **Поиск в векторной базе знаний** (ChromaDB) - семантический поиск по документам
3. **Поиск в интернете** (Tavily) - получение актуальной информации из интернета

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Все настройки находятся в `config.py`:
- `AGENT_LLM_MODEL` - модель LLM (по умолчанию `google/gemini-2.5-flash-lite`)
- `AGENT_MAX_ITERATIONS` - максимальное количество шагов (по умолчанию 12)
- `TAVILY_API_KEY` - API ключ для Tavily
- `STOCK_QUOTES_DEFAULT_PERIOD_DAYS` - период по умолчанию для котировок (30 дней)
- `VECTOR_DB_DEFAULT_RESULTS` - количество результатов поиска в БД (5)
- `TAVILY_MAX_RESULTS` - количество результатов веб-поиска (5)

## Использование

### Одноразовый запрос

```bash
python agent.py "Какая текущая цена акций AAPL?"
```

### Интерактивный режим

```bash
python agent.py --interactive
```

или

```bash
python agent.py -i
```

### Управление памятью

**С памятью (для прода):**
```bash
python agent.py --memory "Какая цена AAPL?"
```

**Без памяти (для тестирования):**
```bash
python agent.py --no-memory "Какая цена AAPL?"
```

## Примеры запросов

### Котировки акций

```bash
# Американские акции
python agent.py "Какая текущая цена акций Apple?"

# Российские акции (добавляйте .ME)
python agent.py "Какая цена акций Газпрома?"
```

### Поиск в базе знаний

```bash
python agent.py "Что такое инвестиции?"
python agent.py "Расскажи про облигации"
```

### Поиск в интернете

```bash
python agent.py "Какие последние новости про Apple?"
```

### Комбинированные запросы

```bash
python agent.py "Какая цена AAPL и что говорит база знаний о технологических акциях?"
python agent.py "Сравни цену Газпрома с последними новостями о компании"
```

## Логирование

Все действия агента логируются в папку `logs/` с именем файла `agent_YYYYMMDD_HHMMSS.log`.

## Особенности

### Российские акции

Для российских акций обязательно добавляйте `.ME` к тикеру:
- Газпром: `GAZP.ME`
- Сбербанк: `SBER.ME`
- Яндекс: `YNDX.ME`

Агент автоматически определяет, что нужно использовать российский формат, если вы упоминаете российские компании.

### Обработка ошибок

Если один из инструментов вернул ошибку:
- Агент попытается использовать другие инструменты
- Вернет частичные результаты, если они есть
- Объяснит пользователю проблему

### Ограничения

- Максимальное количество шагов: 12 (настраивается в `config.py`)
- Это предотвращает зацикливание агента

## Архитектура

Агент использует стратегию **ReAct** (Reasoning + Acting):
1. Анализирует запрос пользователя
2. Выбирает нужные инструменты
3. Выполняет действия
4. Анализирует результаты
5. Формирует финальный ответ
