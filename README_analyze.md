# Анализ векторной базы данных

Скрипт `analyze_vector_db.py` создает подробную статистику и визуализации для векторной базы данных.

## Запуск

```bash
python analyze_vector_db.py
```

## Что создается

### Текстовый отчет
- Файл: `vector_db/statistics/vector_db_statistics.txt`
- Содержит подробную статистику по всем метрикам

### Визуализации (PNG, 300 DPI)
1. **distribution_by_source_pie.png** - Круговая диаграмма распределения по источникам
2. **chunks_by_source_bar.png** - Столбчатая диаграмма количества чанков по источникам
3. **chunk_size_distribution.png** - Гистограмма распределения размеров чанков
4. **size_ranges_distribution.png** - Распределение по диапазонам размеров
5. **top_docs_by_chunks.png** - Топ-10 документов по количеству чанков
6. **chunk_size_by_source_boxplot.png** - Box plot распределения размеров по источникам
7. **chunks_by_type.png** - Распределение по типам документов

## Содержимое статистики

### Общая статистика
- Общее количество чанков
- Количество уникальных документов
- Общее количество токенов и символов
- Размерность эмбеддингов

### Статистика по размерам
- Средний, медианный, минимальный, максимальный размер чанков
- Стандартное отклонение
- Распределение по диапазонам (0-100, 100-200, 200-300, 300-400, 400-512, >512 токенов)

### Статистика по источникам
- Количество чанков по каждому источнику (alph, moex, fincult, gazprom, books, fin)
- Процентное соотношение
- Средний размер чанка по источникам

### Статистика по типам
- Количество чанков по типам (статья/документ)
- Средний размер чанка по типам

### Статистика по документам
- Среднее и медианное количество чанков на документ
- Топ-10 документов по количеству чанков
- Топ-10 документов по количеству токенов

### Статистика по заголовкам
- Количество чанков с/без заголовков разделов
- Топ-20 наиболее частых заголовков

## Требования

Убедитесь, что установлены все зависимости:
```bash
pip install -r requirements.txt
```
