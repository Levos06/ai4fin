СЛОВО ДНЯ — EPS 
--------------------------------------------------

Многие инвесторы составляют список финансово успешных компаний с целью инвестировать денежные средства. Оценивается финансовая отчетность компании, в которой отражаются ключевые показатели, а именно: убытки и прибыль. Если проанализировать отчетность - можно понять текущее финансовое состояние компании и ее перспективы. Публичные компании размещают свою отчетность в открытом доступе, поэтому любой инвестор может её изучить.

Один из показателей, который интересен инвесторам, называется EPS.


 ДЛЯ ЧЕГО EPS НУЖЕН ЧАСТНОМУ ИНВЕСТОРУ?
--------------------------------------------------

EPS (Earnings per share) — прибыль на акцию.

EPS — финансовый показатель, равный отношению чистой прибыли компании к среднегодовому числу обыкновенных акций. Обычно данный показатель рассчитывают для оценки инвестиционной привлекательности компании.

• EPS при увеличении прибыли компании или уменьшении количества акций.

• EPS при снижении прибыли компании или увеличении количества акций.

Показатель EPS используется для определения эффективности работы компании и расчета мультипликатора P/E, который позволяет инвестору сделать правильный выбор для инвестиций.


 ВИДЫ EPS:
--------------------------------------------------

• Фактический EPS. Называется фактическим, потому что расчёт основывается на последней опубликованной отчётности компании.

• Разводненный EPS. Чаще всего используется для компаний со сложной структурой капитала. Конвертируемые облигации и опционы могут конвертироваться в обыкновенные акции. Тогда количество акций вырастет, а EPS снизится.

• Форвардный (прогнозный) EPS. В этом случае используется прогнозируемая аналитиками прибыль. Показатель довольно субъективен, поскольку в реальности прибыль не всегда сходится с ожиданиями.

• Денежный EPS. В этом случае для расчета используется денежный поток от операционной деятельности компании. Таким образом показатель считается более надежным, так как управлять денежным потоком намного труднее, чем чистой прибылью.


ФОРМУЛЫ РАСЧЕТА EPS
--------------------------------------------------

Для фактического:

• если нет привилегированных акций: EPS = чистая прибыль / количество акций;

• если есть привилегированные акции: EPS = (чистая прибыль – дивиденды по привилегированным акциям) / количество акций;

Для разводненного: EPS = чистая прибыль / скорректированное количество акций;

Для прогнозного: EPS = прогнозная чистая прибыль / количество акций;

Для денежного: EPS = денежный поток от операционной деятельности / количество акций.

Пример расчёта:

Например, инвестор решил рассчитать показатель EPS для компании «Ромашка». Привилегированных акций у компании нет.

Чистая прибыль компании по итогам 2020 года составила 315 млрд₽, а количество акций — 12,5 млрд.

Используя формулы, указанные выше, получаем:

EPS «Ромашка» за 2020 год = 315 / 12,5 = 25,2 рубля на акцию.

Данные для расчёта EPS находятся в открытом доступе в финансовой отчётности компании, поэтому рассчитывать самостоятельно чистую прибыль и количество акций не придётся. Нужно всего лишь подставить числа в формулу.
