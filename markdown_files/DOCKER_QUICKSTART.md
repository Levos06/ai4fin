# Быстрый старт с Docker

## Запуск за 3 шага

### 1. Создайте файл `.env` с вашими API ключами:

```bash
cp env.example .env
```

Файл `.env` уже создан с необходимыми ключами. При необходимости вы можете отредактировать его.

### 2. Запустите контейнеры:

```bash
docker-compose up -d
```

### 3. Откройте в браузере:

```
http://localhost
```

## Остановка

```bash
docker-compose down
```
