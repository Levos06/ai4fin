# Быстрый старт веб-интерфейса

## Установка

### 1. Backend

```bash
cd backend
pip install -r requirements.txt
```

### 2. Frontend

```bash
cd frontend
npm install
```

## Запуск

### Запуск Backend (в отдельном терминале)

```bash
cd backend
python run.py
```

Backend будет доступен на `http://localhost:8000`

Проверка работы:
```bash
curl http://localhost:8000/health
```

### Запуск Frontend (в отдельном терминале)

```bash
cd frontend
npm run dev
```

Frontend будет доступен на `http://localhost:3000`

## Использование

1. Откройте браузер и перейдите на `http://localhost:3000`
2. Введите вопрос в поле ввода (например: "Какая цена акций Apple?")
3. Нажмите Enter или кнопку отправки
4. Ответ будет стримиться в реальном времени

## Функции

- **Чат-интерфейс**: Общайтесь с агентом как в ChatGPT
- **Стриминг**: Ответы приходят в реальном времени
- **История**: Все диалоги сохраняются автоматически
- **Экспорт**: Экспортируйте результаты в JSON или TXT
- **Память диалога**: Включайте/выключайте память для контекста

## Устранение неполадок

### Backend не запускается

- Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
- Проверьте, что порт 8000 свободен
- Проверьте логи в консоли

### Frontend не подключается к Backend

- Убедитесь, что Backend запущен на порту 8000
- Проверьте CORS настройки в `backend/api/main.py`
- Проверьте консоль браузера на ошибки

### WebSocket не работает

- Убедитесь, что Backend запущен
- Проверьте, что используется правильный URL: `ws://localhost:8000/api/chat/ws`
- Проверьте консоль браузера на ошибки WebSocket
